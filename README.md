# 多情倒数日 iOS App

自己的倒数日 / 纪念日小工具（SwiftUI 原生）：自定义添加日子，倒数或累计天数，生日可设每年重复，重要日子可置顶，数据只存在手机本地。

- 显示名：多情倒数日
- 包名：top.duoqing.days
- 最低系统：iOS 16
- 构建：推送到 main 后由 GitHub Actions 在 macOS 云端编译出未签名 IPA，并发布到 Releases（build-N）。

## 安装（SideStore 免费签名）

1. 在 Releases 里下载最新的 `DuoqingDays.ipa`
2. 用 SideStore 导入并以自己的 Apple ID 签名安装
3. 免费签名 7 天到期前，在 SideStore 里点刷新即可续上
